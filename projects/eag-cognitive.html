Case study · School of AI Assignment 7

EAG Cognitive Agent

Four-role agentic architecture — Memory, Perception, Decision, Action — with FAISS vector memory, MCP tools, and LLM Gateway V7 as the only model backend.

Repository All School of AI projects

Problem

Tool-using agents need disciplined roles, bounded loops, and retrieval memory without leaking provider credentials into every module.

Role and contribution

Implemented the Session 7 orchestrator (agent7.py), role modules, MCP server tools, FAISS index integration, gateway client, and secret-scanning scripts described in the README.

Architecture

User query
  → memory.remember
  → loop: memory.read → perception → decision (one goal) → action (MCP)
  → FAISS vector index + artifact store
  → LLM Gateway V7 (/v1/embed + chat)

Technical decisions

  • Decision sees one goal at a time to keep tool calls focused.
  • Large payloads go to content-addressable artifacts.
  • Gateway owns model credentials; agent code talks to the gateway only.

Outcome / evidence

Public repository with architecture docs, tests that do not require the gateway, and run scripts.
