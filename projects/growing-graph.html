Case study · School of AI Assignment 8

Multi-Agent Growing-Graph Orchestrator

Session 8 treats a directed graph of skills as the agent loop. Specialized LLM roles execute as nodes; the graph grows as successors are spliced in at runtime.

Repository All School of AI projects

Problem

Linear chat loops struggle with multi-skill work that needs typed handoffs, memory, and the ability to expand the plan while a run is in progress.

Role and contribution

Course assignment implementation around the Session 8 scaffold: agent orchestrator under S8SharedCode/code/ and LLM Gateway V8 under S8SharedCode/gateway/, with documented run logs.

Architecture

Skills graph (Planner, Researcher, Coder, Formatter, …)
  → typed edges between nodes
  → orchestrator grows graph as skills finish
  → LLM Gateway V8 (FastAPI) for chat, routing, embeddings

Technical decisions

  • Graph-shaped control flow instead of a fixed pipeline.
  • Separate gateway service for model access.
  • Runtime expansion of successors rather than a fully static DAG.

Outcome / evidence

Public Assignment-8 repository with architecture write-up and recorded run documentation.
